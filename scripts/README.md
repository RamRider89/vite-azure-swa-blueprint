| [03-build.sh](03-build.sh) | Verificar lint + test + build antes de push |
| [04-deploy-status.sh](04-deploy-status.sh) | Monitorear y debuggear deploys |

Ver [docs/04-scripts.md](../docs/04-scripts.md) para la referencia completa de flags y ejemplos.
